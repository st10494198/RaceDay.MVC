
# RaceDay - Sports Event Management System

## Project Overview
RaceDay is a web-based sports event management system developed using ASP.NET Core MVC and a REST API.

The system allows participants to browse sporting events and manage their event entries. Organisers can create, update and delete events.

## Technologies Used
- C#
- ASP.NET Core MVC
- ASP.NET Core Web API
- .NET 9
- SQL Server
- Entity Framework Core
- HTML
- CSS
- Bootstrap
- JavaScript
- Docker
- Azure Blob Storage

## Main Features
- User registration and login
- Participant and Organiser roles
- Participant dashboard
- Organiser dashboard
- View upcoming sporting events
- Create new events
- Edit existing events
- Delete events
- MVC application communicates with the REST API

## Project Structure
- Controllers - Handles application requests.
- Models - Contains application data models.
- Views - Contains the user interface pages.
- Services - Handles communication with the API.
- wwwroot - Contains CSS, JavaScript and static files.

## How to Run the Project
1. Open the RaceDay.MVC solution in Visual Studio 2022.
2. Ensure the RaceDay API is running.
3. Check that the API base URL is configured correctly.
4. Run the MVC application.
5. Open the application in your browser.

## Project Purpose
This project demonstrates the development of an automated web application using ASP.NET Core MVC, API integration and database connectivity.
